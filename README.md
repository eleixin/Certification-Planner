# 📋 数字认证项目计划工具 (Certification Planner)

一款专为硬件与软件认证排期打造的现代化甘特图可视化规划工具。

---

## 🚀 启动方式

直接双击解压文件夹中的 **`index.html`** 文件即可在浏览器中打开使用。  
无需安装任何软件或环境，支持所有主流浏览器（Edge、Chrome、Firefox 等）。

---

## ✨ 核心功能

- 📊 **交互式甘特图**：清晰展示 Ready、IV、IV Pass、Fixing、DHL、Official 与 Pass 阶段。
- 📌 **指定行插入**：单击选中目标项目后点击 `+ 新建项目`，新项目可精准插入在选中行下方。
- 🔢 **自动序号管理**：第一列自动提供 `#` 序号，随增删插行动态更新。
- 🌐 **Global Ready 批量应用**：在顶部一键配置所有项目的统一 Ready 周次。
- 📊 **Excel 导出**：包含高亮甘特图、标题、周次及底部【图例与阶段说明】。
- 📌 **自定义默认基线**：点击 `📌 设为默认` 锁定满意的数据，随时点击 `🔄 重置` 还原。

---
